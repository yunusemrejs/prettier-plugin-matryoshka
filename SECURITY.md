# Security Policy

## Supported Versions

Only the latest release line is supported with security fixes.

## Reporting a Vulnerability

Do not open public issues for security vulnerabilities.

Please report vulnerabilities privately to maintainers through GitHub Security
Advisories (preferred). Include:

- affected version
- reproduction details
- impact assessment
- suggested remediation (if available)

We will acknowledge reports as quickly as possible and provide status updates
through the advisory thread.
